Plan Colour-Coder

Add the site plan PDFs to get started.
You can add several at once: each page becomes a floor.

Continue where you left off? Adding a PDF instead starts a new project and replaces it.

Or drop PDFs here (including one exported from this app, to carry on editing).
Files stay on this device. Nothing is uploaded.

      Your work is autosaved in this browser. The exported PDF carries the editable project too: open it with + Add PDF on any computer to carry on.
